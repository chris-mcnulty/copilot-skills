# PowerPoint skills

Store Copilot in PowerPoint skill markdown files in this folder.

Use one subfolder per skill, for example:

`powerpoint/<skill-name>/`

## Skills

- [`powerpoint-master-realignment`](powerpoint-master-realignment/SKILL.md) — Safely realigns existing slides to the best compatible layouts under a chosen primary slide master, then consolidates only verified unused redundant masters.
